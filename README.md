## Audio
このフォルダのルートに以下のWAVを置いてください。
home.wav
about.wav
works.wav
discography.wav
stage.wav
diary.wav
contact.wav
404.wav
disc.wav

ブラウザの自動再生制限があるため、環境音はページ初回のクリック/キー操作後に再生を開始します。
右下の「音 ON / 音 OFF」で切り替えられ、設定はブラウザに保存されます。

## Important
discography.html のYouTube URLは仮です。各作品のURLに置き換えてください。
書（ダイアリー）は example.com に仮設定しています。noteのURLに置き換えてください。
contact.html のフォーム送信処理はダミーです。実際の送信先を後から設定してください。

## 404
サーバー側で404.htmlを404ページとして設定してください。
